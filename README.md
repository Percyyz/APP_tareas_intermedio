## 🚀 Descripción del Proyecto

Este repositorio contiene una **aplicación web de gestión de tareas (To-Do List)** construida utilizando únicamente tecnologías de desarrollo web *frontend* puras.

El objetivo principal de este proyecto es demostrar habilidades intermedias en el manejo del **DOM (Document Object Model)**, la interacción del usuario y la persistencia de datos en el navegador.

## ✨ Características Principales

La aplicación permite al usuario gestionar sus tareas diarias de manera eficiente, ofreciendo las siguientes funcionalidades:

* **Añadir Tareas:** Ingresar nuevas tareas a la lista.
* **Marcar como Completada:** Cambiar el estado de una tarea a completada con un solo clic.
* **Eliminar Tareas:** Eliminar permanentemente tareas individuales de la lista.

## 🛠️ Tecnologías Utilizadas

Este proyecto fue desarrollado con las siguientes tecnologías base:

* **HTML5:** Estructura semántica de la aplicación.
* **CSS3:** Estilos y presentación visual de la interfaz.
* **JavaScript (Vanilla JS):** Lógica de la aplicación, manipulación del DOM y gestión del Local Storage.

## 💻 Instalación y Uso

Para probar esta aplicación en tu entorno local, sigue estos sencillos pasos:

1.  **Clonar el repositorio:**
    ```bash
    git clone [https://github.com/Percyyz/APP_tareas_intermedio.git](https://github.com/Percyyz/APP_tareas_intermedio.git)
    ```

2.  **Acceder a la carpeta del proyecto:**
    ```bash
    cd APP_tareas_intermedio
    ```

3.  **Abrir la aplicación:**
    Simplemente abre el archivo `index.html` en tu navegador web preferido. No requiere de un servidor web local para funcionar, ya que es una aplicación puramente estática.
